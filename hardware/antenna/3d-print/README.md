# 3D Print Files & Settings

ASA filament for outdoor parts (tripod adapter).

**Note:** The tripod mount was designed and printed but couldn't be made to work in practice. During observations the horn rested on its narrow (80 mm) wall with the N-connector axis horizontal (E-plane horizontal), not hand-held. Files kept here for reference if someone wants to iterate on the design.
