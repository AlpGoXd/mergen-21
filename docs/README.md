## Audience

The lab manuals are written for an instructor or student at a different institution who has no prior knowledge of this specific project. They assume access to the files in this repository but not to the original authors. Each manual can be completed independently, in order, or selectively.

## Curriculum Sequence

The four labs follow the natural project sequence:

```
Lab 1 (Simulate) → Lab 2 (Build) → Lab 3 (Measure) → Lab 4 (Observe)
```

Lab 4 can be completed without Labs 1–3 if the instructor supplies the assembled hardware or uses the included example data files.
